```text
# RhythmWorld 작업 규칙
- 답변은 한국어로.
- Unity 6 URP 3D 리듬게임. 리듬세상 스타일 도장찍기.
- 박자 값은 절대 바꾸지 말 것: bpm 99.97, firstBeatOffset 0.14초, songEndTime 74초, 첫 서류 9박(First Paper Beat 9).
- 판정은 오디오 DSP 시간 기준(Conductor.SongTimeNow). Time.time 기준으로 바꾸지 말 것.
- 연결된 Unity 에디터가 있으면 `unity status`로 확인하고 에디터를 직접 조작할 것. 씬/프리팹 YAML을 손으로 고치지 말 것.
- 작업 시작: main을 최신으로 받고 새 브랜치를 만든다(이름은 작업 내용으로).
- 작업 끝: 컴파일 에러 확인 → Play 모드로 런타임 에러 확인 → Play 끄기 → 씬 저장 → 커밋. 푸시는 내가 말할 때만.
- 끝나면 바뀐 것, 내가 직접 확인할 것, 남은 질문을 짧게 정리해서 알려줄 것.

## 게임 구조(확정)
- 서류 한 장 = 4박. 1박 예고음+인턴이 건넴(입력 없음), 2박 왼손 도장, 3박 오른손 사인, 4박 인턴 회수+success/fail.
- 서류 3종: 일반(도장 1번, 사인), SECRET(도장 2번: 2박·2.5박, 사인), 함정=부장님 사진(도장 X, 사인 O).
- 키: 도장 F/Space/왼쪽 클릭, 사인 J/오른쪽 클릭. 1~5 채보 전환, R 다시, G 가이드 틱, [ ] 입력 보정.
- 채보: 한 글자 = 서류 한 장. n 일반, s SECRET, t 함정, . 4박 쉼.
- 효과음: Assets/Audio/soundeffect (normal_start, secret_start, Trap_start, stamp_sound, sign_sound, success, fail).
- 화면: 내 머리 뒤 위에서 책상을 내려다봄. 가운데 서류, 왼쪽 도장, 오른쪽 펜, 책상 건너편 미니어처 인턴. 플레이 중 UI 최소.
```

## 1. 판정을 눈으로 보이게: 도장 자국과 사인

```text
판정 결과가 서류 위에 보이게 해 줘. 브랜치 이름은 judge-visual.
- 도장: Perfect는 선명한 빨간 자국이 가운데, Good은 조금 옆으로 밀리고 흐릿하게, Bad/Miss는 자국 없음(함정에 찍은 경우는 비뚤어진 자국).
- SECRET은 두 번 찍은 자국이 겹쳐 보이게.
- 사인: Perfect는 깔끔한 선, Good은 조금 삐뚤어진 선, Miss는 선 없음. 선은 LineRenderer나 얇은 도형이면 충분.
- 자국은 서류의 자식으로 붙여서 4박에 서류와 같이 사라지게.
- 판정 로직과 박자 값은 건드리지 마.
```

확인할 것: 일부러 빠르게, 늦게, 안 누르고 쳐서 자국 모양이 달라지는지.

## 2. 인턴 크기 변화

```text
인턴 크기가 판정에 따라 변하게 해 줘. 브랜치 이름은 intern-scale.
- 서류 한 장이 끝나는 4박(회수) 때 그 서류 결과로 크기를 바꾼다.
- 그 서류의 모든 입력이 Perfect면 10% 커짐, Good이 섞이면 그대로, Bad나 Miss가 하나라도 있으면 10% 작아짐.
- 최소 0.5배, 최대 2배. 크기는 0.2초 정도 부드럽게 바뀌게.
- 크기가 바뀌어도 서류를 건네는 손 위치와 예고음 타이밍은 고정(손이 서류 자리에 정확히 닿게 보정).
- 수치(증감 비율, 최소, 최대)는 Inspector에서 바꿀 수 있게.
```

```text
- 인면에 빨간 인주색을 넣어 줘.
```

## 4. 곡 흐름에 맞춘 본 채보

곡이 확정되면 진행. 곡 구조(마디 길이)를 먼저 알려줘야 한다.

```text
곡 흐름에 맞춘 본 채보를 만들어 줘. 브랜치 이름은 main-chart.
곡 구조는 이렇다(박 번호는 Conductor 기준, 1박=0.14초):
- 도입: 1~8박 (서류 없음, 인턴 대기)
- verse 1: [시작 박]~[끝 박] → 일반 서류만
- verse 2: [시작 박]~[끝 박] → 일반 + SECRET + 함정 섞기
- 4박 무음 휴식: [시작 박]~[끝 박] → 서류 없음
- 빠른 verse: [시작 박]~[끝 박] → 전부 섞기, 마지막 한 장은 SECRET
채보 파일 Assets/Charts/Stage1_Main.asset 로 만들고 StampGame Charts 목록 1번에 넣어 줘.
구간이 4박 단위로 안 맞으면 알려 주고, 내 확인 받고 고쳐.
```

## 5. 입력 보정(캘리브레이션) 화면

```text
입력 지연을 맞추는 보정 기능을 만들어 줘. 브랜치 이름은 calibration.
- 별도 씬 Calibration: 4박마다 '틱' 소리가 나고 스페이스를 박자에 맞춰 8번 누르면 평균 오차(ms)를 보여주고 저장.
- 저장값은 PlayerPrefs "inputOffset"(초). StampController가 시작할 때 이 값을 읽어 inputOffset에 넣게.

```

## 6. 엔딩 연출

```text
곡이 끝난 뒤 엔딩 연출을 만들어 줘. 브랜치 이름은 ending.
- 성공 서류 수 = 결과가 Perfect 또는 Good인 서류 수(Bad/Miss 제외).
- 앞에 쌓인 서류 더미 높이를 5단계로: 성공 비율 0~20%, 20~40%, 40~60%, 60~80%, 80~100%. 단계 기준값은 Inspector에서 바꿀 수 있게.
- 마지막 서류 회수 후 1초 쉬고, 카메라가 2초 동안 고개를 드는 것처럼 EndView 위치로 이동. EndView 마커가 없으면 만들어 줘(위치 (-0.15,0.6,-0.6), 회전 X 18 Y -25에서 시작해 서류 더미와 벽의 부장님 사진이 같이 보이게 조정).
- 부장님 사진: 성공 비율 60% 이상이면 액자에 걸림, 미만이면 살짝 기울고 구겨진 느낌(약간 회전+테이프 도형 2개).
- 연출이 끝나면 결과 화면(다음 단계)으로 넘길 수 있게 이벤트만 열어 둬.
```

## 7. 결과 화면

```text
결과 화면을 만들어 줘. 브랜치 이름은 result-ui. UI는 uGUI든 UI Toolkit이든 프로젝트에 이미 쓰는 쪽으로.
- 엔딩 연출이 끝나면 화면에 표시.
- 표시: 처리한 서류 수, Perfect/Good/Bad/Miss 수, 종류별 성공(일반/SECRET/함정), 등급.
- 등급(임시): 90% 이상 "정규직 전환", 70% 이상 "수습 통과", 50% 이상 "재계약 검토", 그 아래 "짐 싸세요".
- 버튼: 다시 하기(같은 씬 재시작), 타이틀로.
- 플레이 중 디버그 HUD는 결과 화면이 뜨면 숨기고, 빌드에서는 기본으로 꺼지게(개발 빌드에서만 켜짐).
- 한글 폰트가 깨지면 TextMeshPro 한글 폰트 에셋을 만들어 줘.
```

## 9. 일시정지

```text
일시정지를 넣어 줘. 브랜치 이름은 pause.
- Esc로 일시정지/재개. 일시정지 중에는 BGM, 앰비언스, 예약된 효과음이 멈추고, 재개하면 박자가 어긋나지 않게 이어져야 해.
- DSP 시간 기준이라 AudioListener.pause와 Conductor의 시작 시각 보정을 같이 써야 할 거야. 재개 후 판정이 밀리지 않는지 확인해 줘.
- 메뉴: 계속, 처음부터, 타이틀로.
```
